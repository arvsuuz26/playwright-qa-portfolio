# Playwright QA Portfolio

Automated end-to-end tests for a public demo web shop, written with **Playwright** and **Python (pytest)**.

## Goals
- Practice test automation on a realistic e-commerce flow
- Show test design skills from 7 years of software verification and QA

## Planned test coverage
- [ ] Login: valid user, wrong password, locked user
- [ ] Product search and filtering
- [ ] Add to cart / remove from cart
- [ ] Checkout form validation
- [ ] Test report (HTML) for each run

## Tech
- Python 3
- Playwright
- pytest

Work in progress.
